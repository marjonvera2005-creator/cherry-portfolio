# Cherry Mae Atibula Portfolio

Personal portfolio website built with Next.js.

## Requirements

Install these first:

1. [Node.js](https://nodejs.org) 20.9 or newer
2. [Git](https://git-scm.com)

## How to run it

1. Download the project:

   ```
   git clone https://github.com/marjonvera2005-creator/cherry-portfolio.git
   ```

2. Open the project folder:

   ```
   cd cherry-portfolio
   ```

3. Install the packages:

   ```
   npm install
   ```

4. Start the website:

   ```
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

## Windows error: "running scripts is disabled"

Use `npm.cmd` instead of `npm`, for example:

```
npm.cmd install
npm.cmd run dev
```

## Deploying

The site is hosted on Vercel. Push to the main branch to update it:

```
git add .
git commit -m "Describe the change"
git push
```
